MeDataHub - Deteksi Duplikat Data Pasien

Menjaga kualitas data kesehatan dengan mendeteksi record pasien yang duplikat atau tercatat tidak konsisten. Semua proses berjalan langsung di browser kamu - tidak ada data yang dikirim ke server manapun.

Upload file CSV data pasien (kolom wajib: id_record, nama, tgl_lahir, nik, alamat), atau klik "Buat Data Contoh" untuk langsung mencoba dengan data dummy.
Makin rendah = makin sensitif (lebih banyak tertangkap, lebih banyak false positive).
